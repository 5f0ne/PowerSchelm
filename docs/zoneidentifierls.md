# Invoke-ZoneIdentifierListing

Lists all Zone Identifier Values from Alternate Data Streams 

## Usage

`.\Invoke-ZoneIdentifierListing.ps1 -Path [STRING] -Output [STRING]`

| Option | Type   | Default                           | Description                          |
| ------ | ------ | --------------------------------- | ------------------------------------ |
| Path   | String | -                                 | Path to Windows partition (e.g.: C:) |
| Output | String | .\results\zone-identifier-listing | Path to write zone identifier output |
