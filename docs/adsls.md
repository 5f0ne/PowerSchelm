# Invoke-ADSListing

Lists all Alternate Data Streams

## Usage

`.\Invoke-ADSListing.ps1 -Path [String] -Output [String]`

| Option | Type   | Default               | Description                          |
| ------ | ------ | --------------------- | ------------------------------------ |
| Path   | String | -                     | Path to Windows partition (e.g.: C:) |
| Output | String | .\results\ads-listing | Path to write zone identifier output |
