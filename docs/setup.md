# Setup 

In order tu use `powerschelm` to it`s full extent, the following dependencies need to be installed and available in path:

| Name         | Source                                                                           |
| ------------ | -------------------------------------------------------------------------------- |
| .NET         | https://dotnet.microsoft.com/en-us/download/dotnet                               |
| sysinternals | https://learn.microsoft.com/en-us/sysinternals/downloads/sysinternals-suite      |
| capa         | https://github.com/mandiant/capa/releases                                        |
| eztools      | https://ericzimmerman.github.io/#!index.md                                       |
| hayabusa     | https://github.com/Yamato-Security/hayabusa/releases                             |
| kape         | https://www.kroll.com/en/publications/cyber/kroll-artifact-parser-extractor-kape |
| perl         | https://strawberryperl.com/                                                      |
| sleuthkit    | https://www.sleuthkit.org/sleuthkit/download.php                                 |
| python       | https://www.python.org/                                                          |
| volatility3  | py -m pip install volatility3                                                    |

After installation:

- For `eztools` execute `Get-ZimmermanTools`
- For `hayabusa` install/update the rule set
